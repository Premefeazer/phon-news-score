# NEWS Score · โรงพยาบาลพล

เว็บบันทึกสัญญาณชีพและประมวลผล National Early Warning Score 2 (NEWS2) ตามแนวทางของ Royal College of Physicians (2017)

> เกณฑ์คะแนนเป็นไปตาม NEWS2 (สีแดง ≥ 7)

## วิธีเปิดใช้งาน
เป็นเว็บแบบ static ไม่ต้องมีฐานข้อมูลหรือเซิร์ฟเวอร์พิเศษ
- **ทดสอบในเครื่อง:** `python -m http.server 8765` แล้วเปิด http://localhost:8765
- **ใช้งานจริง:** วางทั้งโฟลเดอร์บนเว็บเซิร์ฟเวอร์ของโรงพยาบาล (IIS / Apache / Nginx) หรือ GitHub Pages / Netlify ก็ได้

## โครงสร้าง
```
index.html            หน้าเว็บ (บันทึก / ชีต / เกณฑ์)
assets/css/style.css  ธีมและเลย์เอาต์ (รวมรูปแบบสำหรับพิมพ์/PDF)
assets/js/news.js     สูตรคิดคะแนน NEWS2 + ข้อปฏิบัติ 4 ระดับสี  ← แก้เกณฑ์ที่นี่
assets/js/store.js    การจัดเก็บข้อมูล (localStorage, ลบอัตโนมัติ 24 ชม.)
assets/js/app.js      การทำงานของหน้าเว็บ, pop-up, ชีต, ส่งออก Excel/CSV/PDF
assets/img/logo.svg       ตราโรงพยาบาลพล (เวกเตอร์ ใช้ในเมนู)
assets/img/favicon.svg    ไอคอนแท็บเบราว์เซอร์
assets/img/logo-mark.png  ตราสำหรับหัวรายงาน PDF / พิมพ์
assets/img/logo-full.jpg  ไฟล์ตราต้นฉบับ
```

ข้อเสนอแนะการพัฒนาต่อ ดูที่ [ข้อเสนอแนะ.md](ข้อเสนอแนะ.md)

## ข้อควรทราบ
- ข้อมูลเก็บใน **เบราว์เซอร์ของเครื่องที่บันทึก** เท่านั้น เครื่องอื่นจะไม่เห็นข้อมูลชุดเดียวกัน
- ข้อมูลถูกลบอัตโนมัติเมื่อครบ 24 ชม. นับจากเวลาบันทึก — ควรส่งออก Excel/PDF ก่อนหากต้องการเก็บ
- การส่งออก Excel/PDF ใช้ไลบรารีจาก CDN (SheetJS, html2pdf.js) ถ้าเครื่องไม่มีอินเทอร์เน็ต ระบบจะสลับเป็น CSV / หน้าพิมพ์ให้อัตโนมัติ
- การแจ้งเตือนเมื่อถึงเวลาประเมินซ้ำ (เสียง + ข้อความ) ทำงานเฉพาะตอนที่เปิดหน้าเว็บนี้ค้างไว้ และต้องกดเปิดสวิตช์ในหน้าชีตก่อน
- ใช้ SpO₂ Scale 1 เท่านั้น (ผู้ป่วยอายุ ≥ 15 ปี ไม่มีภาวะหายใจล้มเหลวเรื้อรัง)
